How bootstraps are managed today: there is no dedicated bootstrap server. Any running node can be one, and the operator hands its address to new nodes out of band (on the command line in the tutorials). FreePastry ships no bootstrap list, rotation or health check, so operators should run several bootstrap nodes on hardened hosts.

Does a joining node trust its bootstrap? In certified mode it trusts it to be a certified node, not to tell the truth: the bootstrap only forwards the JoinRequest, but if the bootstrap or the root it reaches is malicious, the joiner cannot tell a forged leaf set from the real one, because it has only one answer. Probing proves that each returned node exists at its address, not that it is the right neighbour. Leaf-set maintenance later pulls in honest neighbours if any of them reach the new node. Wave C4 fixes this properly: ask several independent bootstraps, keep the numerically closest answers, and check that the ids in the leaf set are not suspiciously dense.
