# FreePastry

A modular, open-source implementation of the [Pastry](http://freepastry.org/) peer-to-peer structured overlay network.

## Requirements

- Java 25 (LTS) or higher
- Apache Maven 3.9+ (or use the bundled wrapper: `./mvnw`, pinned to Maven 3.10.0)

With [SDKMAN!](https://sdkman.io/), run `sdk env install` in the project root to get the exact JDK and Maven versions from `.sdkmanrc`.

The compiler runs with `-Xlint:rawtypes,deprecation,removal,dep-ann -Werror`: raw (untyped) generic types and calls to deprecated APIs fail the build. Failing tests fail the build too.

## Quick Start

### Build

```bash
mvn clean compile
```

This compiles the source code into the `target/classes/` directory.

### Create JAR

```bash
mvn package
```

This creates `freepastry-2.1.0.jar` in the `target/` directory.

### Run Tests

```bash
mvn test
```

To run a specific test:

```bash
mvn test -Dtest=LivenessTest
```

**Note**: Tests run sequentially to avoid port conflicts. Some tests may fail due to timing issues or network configuration - this is normal for this legacy codebase and won't block the build.

### Run Hello World Example

Start a standalone node:

```bash
mvn exec:java -Dexec.mainClass="rice.pastry.testing.DistHelloWorld"
```

Or using the JAR:

```bash
java -cp target/freepastry-2.1.0.jar rice.pastry.testing.DistHelloWorld
```

Start additional nodes that connect to the first node:

```bash
java -cp target/freepastry-2.1.0.jar rice.pastry.testing.DistHelloWorld -bootstrap <hostname>
```

### Create JAR with Dependencies

```bash
mvn assembly:single
```

This creates a JAR with all dependencies included.

## Common Maven Commands

- `mvn clean` - Remove generated files
- `mvn compile` - Compile source files
- `mvn test` - Run tests
- `mvn package` - Create JAR file
- `mvn javadoc:javadoc` - Generate API documentation (output to `target/site/apidocs/`)
- `mvn install` - Install to local Maven repository
- `mvn assembly:single` - Create JAR with dependencies

## Project Structure

- `src/` - Java source files
- `target/` - Compiled classes and JARs (generated by Maven)
- `jars/freepastry/` - Configuration files
- `docs/` - Comprehensive documentation and release notes
- `html/rawtutorial/` - Tutorial files
- `pom.xml` - Maven project configuration

## Dependencies

FreePastry uses the following libraries (managed by Maven):

- Bouncy Castle (bcprov) - Cryptography
- Apache Commons JXPath - XML processing
- Apache Commons Logging - Logging framework
- XML Pull Parser - XML parsing
- XPP3 - XML parsing
- SBBI UPnP Library - UPnP support
- JUnit 6 (Jupiter, plus the Vintage engine for the JUnit 4 tests) - Testing framework

## Documentation

- Full release notes and detailed documentation: `docs/README.html`
- Javadoc API documentation: Generate with `mvn javadoc:javadoc`, view at `target/site/apidocs/index.html`
- Tutorial examples: `src/rice/tutorial/`

## Applications

FreePastry includes several P2P applications:

- **PAST** - Distributed hash table and archival storage
- **Scribe** - Application-level multicast
- **SplitStream** - High-bandwidth multicast
- **Glacier** - Archival storage with high durability
